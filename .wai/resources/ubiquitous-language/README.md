# Ubiquitous Language

This directory contains the core domain concepts and terminology for XAct.jl, organized by bounded context.

## Bounded Contexts
- [Tensor Algebra](contexts/tensor-algebra.md) - Manifolds, indices, canonicalization, and symmetries.
- [Verification](contexts/verification.md) - Oracles, parity tests, and cross-adapter benchmarks.

## Usage
These terms are **normative**. AI agents and developers SHALL use this terminology consistently across:
- Source code (variables, types, and comments)
- Documentation and tutorials
- Issue tracking (beads) and change proposals (openspec)
- Handoff documents
