# Context: Verification

## Key Terms
- **Oracle**: A ground-truth engine (usually Wolfram/xAct) used for result validation.
- **Parity Test**: A test comparing output between the Julia/Python implementation and the Wolfram Oracle.
- **CIR (Canonical Intermediate Representation)**: A standardized, serialized format (JSON/AST) used to enable exact mathematical comparison between the sxAct implementation and the Wolfram/xAct ground truth.
